# 4_merged_data

In this folder, we stash processed and merged files, containing all acoustic and kinematic information. The files were generated by 'icphs_processing-script'

column description:

- time_ms - time in milisecouns

- F0 - fundamental frequency

- x_fing - x-coordinate of finger marker

- y_ - y-coordinate

- z_ - z-coordinate (used in analysis)

- _wrist - wrist marker

- _elb - elbow marker

- speed_ - velocity

- acc_ - acceleration

- syllable - current syllable

- syllable_num - the number of current syllable (in order)

- participant - participant

- hand - pointing hand (left vs. right)

- speed_condition - condition of speech rate (normal vs. fast)

- rhyme - number of rhyme (in order)

- condition_speech - motion condition vs. reading condition

- movement direction - is the hand pointing backward (to oneself) or forward (to teddy bear)

- gesture phase - number of gesture phase (in order), NA when no pointing

- speech - is the speech ongoing?

- rhyme_name - name of the rhyme
