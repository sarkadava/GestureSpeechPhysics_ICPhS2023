# 8_datasets_for_statistical_analysis

These datasets were used for statistical analysis and modelling and were generated by script 'icphs_datawrangling_and_plotting'

column description:

- speaker = participant

- point_hand = pointing hand

- sp_rate = speech rate

- rhyme = name of the rhyme

- env_syllable = syllable in this moment (according to envelope peak)

- env_syllable_num = number of this syllable

- point_direct = direction of hand in this phase

peaks:

- fing_ = finger measures

- wrist_ = wrist measures

- _mpeak = movement peak (z-dimension)

- _mpeak_time = time of this peak

- envpeak_m = envelope peak relative to movement peak (nearest in time)

- envpeak_m_time = time of this peak

- movenv_sync = difference in timing of movement and envelope peak

- attpeak_m = envelope attack (slope) peak relative to movement peak

- attpeak_m_time = time of this peak

- movatt_sync = difference in timing of movement and env attack peak

- f0peak_m = f0 peak relative to movement peak (nearest in time)

- f0peak_m_time = time of this peak

- movf0_sync = difference in timing of movement and f0 peak

- vpeak = velocity peak

- vpeak_time = time of this peak

- envpeak_vel = envelope peak (relative to velocity peak)

- envpeak_vel_time = time of this peak

- fing_velenv_sync = difference in timing of velocity and envelope peak

- attpeak_vel = env attack peak relative to velocity peak

- attpeak_vel_time = time of this peak

- velatt_sync = difference in timing of velocity and attack peak

- f0peak_vel = f0 peak relative to velocity peak

- f0peak_vel_time = time of this peak

- velf0_sync = difference in timing of velocity and f0 peak

- apeak = acceleration peak

- apeak_time = time of this peak

- envpeak_acc = envelope peak relative to acceleration peak

- envpeak_acc_time = time of this peak

- accenv_sync = difference in timing of acceleration and envelope peaks

- attpeak_acc = attack peak relative to acceleration

- attpeak_acc_time = time of this peak

- accatt_sync = difference in timing of acceleration and attack

- f0peak_acc = f0 peak relative to acceleration

- f0peak_acc_time = time of this peak

- accf0_sync = difference in timing of acceleration and f0 peaks

- decpeak  = deceleration peak

- decpeak_time = time of this peak

- envpeak_dec = envelope peak relative to deceleration

- envpeak_dec_time = time of this peak

- decenv_sync = difference in timing of deceleration and envelope peak

- attpeak_dec = attack peak relative to deceleration

- attpeak_dec_time = time of this peak

- decatt_sync = difference in timing deceleration and attack peak

- f0peak_dec = f0 peak relative to deceleration

- f0peak_dec_time = time of this peak

- decf0_sync = difference in timing of deceleration and f0 peaks
