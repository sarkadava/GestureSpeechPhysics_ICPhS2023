# 1_primary_data_to_be_processed

This folder contains raw data,

1) data_motion	

- motion data converted from C3D files into csv files

- folder 'marker_info' with information about markers, their names, etc.

2) data_audio	

- wav. files cannot be shared because of a lack of consent

- TextGrid files with sylable annotations (automatically using WebMAUS,Kisler et al., 2017; followed by manual correction for syllable intervals)

3) 'info.xlsx' 

- non-identifiable metadata and randomized order of trials-rhymes

4) 'rhyme_order.xlsx'

- documentation of randomized order of rhymes for participants
