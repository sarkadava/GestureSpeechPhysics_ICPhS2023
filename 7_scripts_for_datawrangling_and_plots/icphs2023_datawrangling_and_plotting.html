Introduction

In this notebook we do analysis for ICPhS paper on gesture-speech physics in counting-out rhymes

Detailed explanation of the study and the type of data and variables

Eleven native speakers (three male) of Polish were asked to perform six counting-out rhymes in two different movement conditions and one still condition. The movement conditions involved the counting-out movement with the left or the right hand, and the still condition involved reading the rhyme without any movement. All speakers were right-handed. Additionally, in the movement conditions, speakers were asked to repeat the rhyme with enhanced speed, resulting in another condition.

Altogether, these sum up to five conditions:

  • left hand normal speed
  • left hand fast speed
  • right hand normal speed
  • right hand fast speed
  • reading

The order of the blocks was the same for all participants (reading, natural, fast), but the order of counting-out rhymes was randomized as well as whether they began with the dominant or non-dominant hand.

In all of those conditions, the participants performed six counting-out rhymes, the order of which was randomized across participants (cf. rhyme_order.xlsx or columns 6:11 in info.xlsx).

The participants were asked to perform each rhyme with a confederate teddy bear placed in front of them. For each condition, the participants were standing.

Data wrangling and annotation

We detect outliers using function outlierKD that removes them by Tukey rules on quartiles +/- 1.5 IQR. This code should be run in the console, because the function prompts the user to answer whether they wish to remove the outliers or not.

#Function adapted from: http://goo.gl/UUyEzD
# in the form of outlierKD(f0_dec, wrist_f0peak_dec)

outlierKD <- function(dt, var, group = NULL, plot = TRUE, verbose = TRUE) {
  var_chr <- deparse(substitute(var))
  x <- dt[[var_chr]]

  na1     <- sum(is.na(x))
  n_valid <- sum(!is.na(x))
  m1      <- mean(x, na.rm = TRUE)

  # flag boxplot outliers (1.5 * IQR rule), optionally within groups
  flag_out <- function(v) {
    out <- boxplot.stats(v)$out
    !is.na(v) & v %in% out
  }
  if (is.null(group)) {
    is_out <- flag_out(x)
  } else {
    is_out <- as.logical(ave(x, dt[[group]], FUN = flag_out))
  }

  x_clean <- x
  x_clean[is_out] <- NA

  if (plot) {
    op <- par(mfrow = c(2, 2), oma = c(0, 0, 3, 0))
    on.exit(par(op))
    boxplot(x, main = "With outliers")
    hist(x, main = "With outliers", xlab = NA, ylab = NA)
    boxplot(x_clean, main = "Without outliers")
    hist(x_clean, main = "Without outliers", xlab = NA, ylab = NA)
    title(paste("Outlier check:", var_chr), outer = TRUE)
  }

  if (verbose) {
    n_out <- sum(is_out)
    cat("Variable:", var_chr, if (!is.null(group)) paste0("(within ", group, ")"), "\n")
    cat("Outliers identified:", n_out, "\n")
    cat("Proportion (%) of outliers:", round(n_out / n_valid * 100, 1), "\n")
    cat("Mean of the outliers:", if (n_out > 0) round(mean(x[is_out]), 2) else NA, "\n")
    cat("Mean with outliers:", round(m1, 2), "\n")
    cat("Mean without outliers:", round(mean(x_clean, na.rm = TRUE), 2), "\n")
  }

  dt[[var_chr]] <- x_clean
  invisible(dt)
}

# helper: publication-style plot (as in dec-env), without facetting
pub_plot <- function(data, x, y, xlab, ylab, reverse_x = FALSE, ylims = NULL) {
  p <- ggplot(data, aes(x = {{ x }} * 100 * 200, y = {{ y }})) +
    geom_point(size = 0.5, alpha = 0.5, color = "black") +
    geom_smooth(method = loess, formula = y ~ x, color = "black", linetype = "dashed",
                linewidth = 0.4, fill = "gray", alpha = 0.5) +
    geom_smooth(method = lm, formula = y ~ x, color = "red", linewidth = 1, fill = "red") +
    labs(x = xlab, y = ylab) +
    theme_cowplot(12) +
    theme(title = element_text(size = 10), text = element_text(family = "times"))
  if (reverse_x)        p <- p + scale_x_reverse(labels = abs)
  if (!is.null(ylims))  p <- p + ylim(ylims)
  p
}
